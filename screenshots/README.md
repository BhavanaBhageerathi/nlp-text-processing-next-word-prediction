# NLP Text Processing and Next Word Prediction – Screenshots

This folder contains screenshots demonstrating the various Natural Language Processing (NLP) techniques implemented using NLTK and spaCy.

## Screenshots Included

*  – Demonstrates splitting the input text into individual words using NLTK.
*  – Shows the filtered tokens after removing common English stopwords.
*  – Demonstrates stemming and lemmatization of filtered tokens.
*  – Displays Part-of-Speech (POS) tagging using spaCy.
*  – Shows Bigram generation and next-word prediction results.

## Technologies Used

* Python
* NLTK
* spaCy
* WordNet
* Bigram Language Model
